# AI Disclosure

---
disclosure-default: none
  (i.e. human authorship)

models-used:
  (see respective entries in source code)

providers:
  (see respective entries in source code)

scope:
  (see respective entries in source code)

  Application code and documentation are human-written
  unless headers say otherwise.

last-updated:
  2026-06-26

---

Per-file headers override these values; the disclosure and level must always be
explicit in every file with authorial AI usage (implying human authorship if absent).

Apart from obvious exceptions (AGENTS.md, necessarily):

- Files that are fully AI-generated have the suffix `_AI` or `.ai` in
their filename, and carry a source header noting the tool, date,
reviewing status, and key phrases of the prompts.

- Files that received
AI-assisted edits, but otherwise have human authorship, have the
disclosure info as a short header plus local details near the changed lines.

- Source files without a disclosure header have full human authorship (in this
repository, as far as they originate from it).

See ai_conventions.ai.md for the full reference.
