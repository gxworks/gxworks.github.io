TimeKeep - sample date conversion (BWQ v. 0.26.26)

Displays dates in five formats: J2000 seconds (seconds since J2000.0), UTC/G/J (UTC, Gregorian or Julian calendar), Julian Days, ISO week (CAT) (ISO week date based on atomic time), and Civil Atomic Time (TAI-based atomic time since J2000.0). This data comes with ABSOLUTELY NO WARRANTY. Be aware of possible rounding errors.

This page is a first sample of projects from bwq.sf.net and github.com/gxworks. For an overview see: overview.html — for more details: timekeeping.

Enter a date (e.g. 2002-02-02) and click Use date to include it in the table.

Demonstrates DateFunc time/date conversions from the BWQ Java library, compiled to JS via J2CL.
