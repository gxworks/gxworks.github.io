AI disclosure conventions used in the repositories

Files that are fully AI-generated (like this one) have the suffix '_AI' or '.ai' in their filename, and carry a source header noting the tool, date, reviewing status, and key phrases of the prompts. Files that received AI-assisted edits note the same info near the changed lines. The only exception is AGENTS.md, necessarily: no suffix for the file name.

Common alternatives seen elsewhere:

ApproachProCon
Co-authored-by: AI <...> in commit trailersBlocks in git historyInvisible outside git log/blame
Header comment only (no suffix)Less rename churnNot visible in ls/glob
Git commit prefix "[ai]"Ties metadata to commitsDoesn't mark individual files
.gitattributes linguist-generatedHides from diff statsNo provenance info
No convention at allZero overheadNo audit trail at all

The convention in this repo is more verbose but also more informative. The overhead pays for itself given the project is a small POC where provenance matters for fact-checking.
